# 天気条件の取得

仕様§67に従い、天気・気温は背景条件の判定にのみ使います。気象データ自体の表示やクラウド同期は行いません。地域は既存の `settings.themeRegion`（緯度・経度）を太陽時テーマと共有します。この設定は一般設定同期の対象です。外観の地域設定で手動入力、現在地の取得、地域解除を行えます。地域画面には送信先と同期の案内、提供元リンクを表示します。

## サーバー設定

Git除外の `config/config.php` で `weather` を設定できます。既存の設定ファイルに項目がない場合は下記の既定値で動作します。新規Installerも項目を生成します。

```php
'weather' => ['enabled' => true, 'mode' => 'non-commercial', 'api_key' => ''],
```

取得元は[Open-Meteo Forecast API](https://open-meteo.com/en/docs)。無料公開APIは非商用向けです。商用利用は提供元の[料金・利用条件](https://open-meteo.com/en/pricing)に従い、`mode` を `customer` に設定し、契約したAPIキーを `api_key` に入力してください。キーはサーバーだけが扱い、ブラウザ・進捗記録・Gitに渡しません。任意の接続先URLは受け付けません。`enabled=false` で天気取得を停止できます。

Open-Meteoの `current.temperature_2m`（摂氏）、`current.weather_code`、UNIX時刻を取得します。公式WMO一覧に従い clear/cloudy/fog/rain/snow/storm に分類し、雷雨コード97も扱います。観測時刻が2時間より古い、15分以上未来、値や単位が不正な応答は利用しません。

## API・保存・失敗時

`POST /api/weather` に数値の `latitude`、`longitude` とCSRFヘッダーを送ります。ゲストも利用でき、DB接続や認証情報は必要ありません。範囲は緯度±90・経度±180、送信地域は小数2桁へ丸めます。未知のキーや文字列座標は422、CSRF不正は403、取得不可は503、接続元IPごとの毎分30回を超える要求は429です。座標をブラウザからのURLに入れません。

成功応答には `weather`、`temperature`、`observedAt`、`expiresAt` だけを返します。HTTPS証明書を検証し、リダイレクトを拒否、応答32KiB・通信約4秒の上限を設けます。接続エラーのURLやAPIキーを例外メッセージに含めません。PHP標準HTTPSストリームを使い、cURL追加を必須にしません。

サーバーの私有 `storage/weather` に最大256スロットのキャッシュを保持します。地域と設定のハッシュを照合し、成功15分・失敗60秒で再取得。地域やキーの実値はキャッシュに記録しません。設定無効化・契約モードやキーの変更をキャッシュより先に検査します。キャッシュはユーザーDB/Migrationへ追加しません。

ブラウザは地域未設定、背景ライブラリ未使用、条件切替以外、天気/気温条件なしの場合に取得しません。通信中は背景を描画でき、取得後に条件を再判定します。期限切れ・失敗時は天気/気温を未知として扱い、他の条件と既存の選択フォールバックを維持します。失敗時は60秒後に再試行。地域変更時は旧通信を中止し、遅れて届いた旧地域の応答を採用しません。実データはメモリだけに保持します。

## 検証

- `php tests/weather.php`: 座標、WMO分類、単位/時刻/応答サイズ、不正応答、キー/モード、キャッシュ/期限/失敗再試行、Controllerの成功・拒否。
- `node tests/weather-context.test.mjs`: 製品の背景条件選択、地域丸め、通信重複防止、期限、通信失敗、地域変更の旧応答拒否、地域の同期投影と受信。
- `node tests/weather-http.mjs http://127.0.0.1:8085`（MariaDBは8086）: 隔離環境の実API/CSRF/Validation、公開都市座標の実Open-Meteo取得、通常トップの回帰。提供元が取得できない場合は失敗時処理だけを確認し、実成功は未確認として出力します。

`tests/region-settings.test.mjs` は位置取得の生成モデルで成功、ゼロ座標、丸め、許可拒否、取得不可、時間切れ、非対応、遅い応答を検証します。実OSの位置取得許可と認証済み製品ブラウザでの地域同期はまだ未確認です。実ブラウザでは手動保存/再読み込み/範囲外拒否/解除とJA/EN・390px表示、実天気・気温による背景切替と地域解除時の条件不一致への復帰を確認しました。位置の許可を自動で承認せず、モデルと実許可を区別します。

実画面検証でブラウザのnative fetchを別オブジェクトのメソッドとして呼ぶと失敗する問題を検出し、global receiverを保つラッパーへ補修しました。Nodeの注入fetchモデルだけでは見つからなかったため、既定fetchのreceiverも回帰試験へ追加しています。地域の成功表示は原子的な設定・履歴保存の完了を待ち、保存失敗時は未保存の入力を保持します。
