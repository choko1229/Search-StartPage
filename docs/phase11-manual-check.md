# Phase 11 実Chrome検証

対象は隔離環境と生成テストユーザーだけ。通常環境8099/8100・実Discordアカウント・本番設定は使わない。実Chromeの拡張ページが操作ツールの一覧に現れない場合の手動手順。Nodeの模擬Cookie試験と区別して記録する。

## 現在確認できたこと

- 2026-10-07、ユーザーが旧MySQL候補を読み込み、新しいタブに検索画面が表示されたと回答。
- 同日、操作可能なChromeのWeb側で生成ユーザーへのログインとプロフィール表示を確認。Webの警告・エラーログ0。
- 拡張側のプロフィール・同期・Console・Offlineは未確認。表示確認だけでPhase11を完了扱いにしない。

## 準備

同じChromeプロファイルで、次のWebタブと拡張の新しいタブを並べる。接続中のChromeと別のプロファイルで拡張を読み込んだ場合は、そのプロファイルで専用ログイン画面を開き「生成テストユーザーで開始」を押す。

| DB | Web / ログイン | 読み込み済み・基本候補 |
|---|---|---|
| MySQL | http://extension-mysql.localhost:8115/ / http://extension-mysql.localhost:8115/_test/login | `.test-output/extension-mysql-20261006` |
| MariaDB | http://extension-mariadb.localhost:8116/ / http://extension-mariadb.localhost:8116/_test/login | `.test-output/extension-mariadb-20261006` |

まずMySQLで実施する。MariaDB候補の読込・切替は別途具体的な対象を確認してから行う。両方を同時にNewTab置換として有効にしない。

生成ユーザー名は `Generated isolated extension primary`。これは実Discord OAuthの検証ではない。初回案内は「あとで続ける」。初回同期のデータ選択が現れたら、両側が生成テストデータだけであることを確認して選択内容も記録する。判断できない場合は「あとで」で保留。

## オンライン確認

1. 新しいタブを再読込。右上のプロフィールと生成ユーザー名が表示されることを確認。
2. 設定の「クラウド同期を利用する」を確認。「今すぐ同期」で成功表示を確認。
3. 拡張でテスト用お気に入り `Extension check R1`（URL `https://example.com/`）を追加。同期成功後にWebを再読込し、同じ項目を確認。Webで `Web check R1` に名前変更し、Web同期成功後に拡張へ戻って変更を確認。
4. 拡張でテーマを変更し、Webへ反映されることを確認。Webで元へ戻し、拡張へ反映されることを確認。地域を使う場合は公開都市のテスト座標だけを使用する。位置取得ボタンは使わない。
5. 拡張で日本語→English→日本語を切替。設定・同期・履歴・お気に入り・起動ページ案内の表示を確認。ブラウザー再読込後も選択言語を保持することを確認。
6. 背景の画像ファイルを取り込み、クラウド同期ONで保存。両側で画像と設定を確認。動画も専用の非公開情報を含まないテストファイルを使い、再生・停止・設定を確認する。
7. 拡張ページの開発者ツールConsoleを確認。CSP違反・未処理例外の有無とエラー名だけを記録。Cookie、Authorization、CSRF値、リクエスト本文、認証情報を貼り付けない。
8. 起動ページの案内が表示され、NewTab置換とChrome起動時の設定の違いが分かることを確認。Chrome起動時設定自体の変更はこの検証に不要。

## オフラインと復帰

拡張タブの開発者ツールのNetworkで、そのタブだけをOfflineにする。OSや他のタブの通信設定は変えない。簡易表示が出ず通常表示のままの場合は、Offline扱いになっていない可能性があるため合格にしない。操作後は必ず元の通信設定へ戻す。

| 機能 | 操作と確認 |
|---|---|
| Search | 検索欄の入力、検索先切替、端末内の履歴候補、キー操作。外部検索結果の取得成功は要求しない。外部候補の通信は停止する。 |
| Favorites | `Offline check R1` を追加・編集。再読込後も残る。 |
| History | 既存履歴の表示と端末内の変更・再読込保持。履歴同期を使う場合はONを明示してから検証。 |
| Theme | テーマ変更、再読込保持。外部フォント設定時は可読な代替表示と設定保持。 |
| Background | 既定背景と取り込んだ画像・動画の切替、再読込描画、動画制御。未保存の外部URL画像をOffline成功とみなさない。 |
| Command Palette | Ctrl+Kで開き、設定・テーマなど端末内操作を実行。 |
| Shortcuts | 表示される検索・履歴キーを操作し、ブラウザーのキーとの競合を記録。 |
| Clock | 表示を有効にして時刻が進むことを確認。 |
| Greeting | 保存済み表示設定と名前・挨拶、再読込後の表示を確認。 |

Offline中の通信は、Network一覧でアプリAPIへの送信が発生していないことも確認する。通信の拒否結果だけで「要求を出していない」と判断しない。

Networkを元へ戻し、その後は「今すぐ同期」を押す前に自動同期の成功を確認する。Webへ戻り、Offline中のお気に入り・設定が反映されることを確認。競合が表示された場合は両側のテスト変更と選択結果を記録し、選ばなかったデータを勝手に失ったと扱わない。ログアウト後、同期データの扱いが画面上の設定どおりであり、別生成ユーザーへの切替で前ユーザーの非公開クラウド背景が取得できないことを確認する。

## URL背景の端末用コピー

旧候補には最新のコピー機能が含まれない。`extension-media-copy-mysql-20261006` / `extension-media-copy-mariadb-20261006` は別候補で、HTTP/HTTPSのoptional host宣言を追加している。基本候補の読込通知をこの候補の権限付与として扱わない。

追加候補を具体的に確認して読み込んだ後、非公開情報を含まないテストURLで「端末用コピーを保存して使用」を検証する。許可拒否時は取得・コピーが行われないこと、対象ホスト1件の許可でコピーを保存できること、元項目が残り新しいコピーの同期がOFFであること、一時的に付与した許可は処理後に解除されること、元からの許可は維持されること、Offline再読込後に画像・動画が描画できることを確認する。許可ダイアログの実操作成功は単体試験で代用しない。
