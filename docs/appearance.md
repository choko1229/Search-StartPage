# 外観設定

設定モーダルの「外観」でテーマ、フォント、アニメーション、検索欄のデザインを変更する。変更は端末のIndexedDBへ保存し、設定同期が有効なら既存の同期経路を使う。設定変更履歴は端末専用で20件。

テーマはLight / Dark / OS / 森 / ローズ / Custom / 日の出・日の入り。Customは6色と名前を保存し、複数のテーマを選択できる。カテゴリ初期化は現在の選択を初期値へ戻すが、保存したテーマ定義は保持する。

日の出・日の入りは手動入力した緯度・経度を使う。地域が未設定ならOSテーマへフォールバックする。位置情報の許可は自動で要求しない。座標は設定同期の対象なので入力欄にその旨を表示する。近似計算の根拠は[NOAAの太陽位置・日の出計算式](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)。極夜・白夜と日付変更線を扱い、表示中は毎分再判定する。テーマの既定フェードは0.75秒。

フォントはSystem / Serif / Monospace / Google Fonts / Custom HTTPS URL。外部フォントはブラウザから配信元へ接続し、説明を設定欄へ表示する。URLはHTTPSのみ、資格情報付きURLを拒否。Google Fonts用の外部CSSとHTTPSフォントをCSPで許可し、スクリプトの制限は維持する。読み込み失敗時はシステムフォントを使用する。

検索欄は既定でレスポンシブ幅（最大900px）、標準高さ56px、中央より上、半透明背景と12pxのぼかし。固定幅320〜900pxも画面幅を超えない。Compact / Standard / Large、背景色・不透明度・ぼかし・枠線色/幅・角丸・影・文字/placeholder色を変更できる。複数行入力とモバイルで内容が増える場合は高さを広げる。

「一般」に挨拶・時計・日付の表示設定を配置。挨拶は既定ON、時計/日付はOFF。時計の12/24時間・秒、日付形式・曜日に対応。ログイン済みユーザー名は既存の認証APIから取得し、textContentで表示する。実Discord認証後の表示はまだ未確認。

AnimationはNone / Low / Standard / Rich（既定）。端末のreduced motion指定を優先してNoneへ切り替える。

時計/日付は独立して検索欄の上/下・画面の4隅へ配置でき、サイズ・ページ/System/Serif/Monoフォント・色・不透明度を保存する。同じ隅の時計と日付は重ならないように配置する。

ヘッダーは既定で上・右寄せ、Settings/History/Discord LoginまたはProfileの導線を持つ。上下配置・左右中央の整列・サイズ・不透明度・背景色・ぼかし、5項目の表示と並び替えに対応。下配置は画面下へ固定する。全項目を隠しても検索欄の設定ボタンから復元できる。

ブラウザで時計の64px/等幅/検索欄の下、ヘッダー下/左寄せ/ぼかし8px/サイト名非表示/並べ替え・再読込・390px表示を確認。日本語/英語の設定を確認、架空地域での昼夜テーマ切替とGoogle Fontsの読み込み完了を確認。地域のカテゴリ初期化は座標入力欄も空へ戻す。

初回ウィザードは8steps（ログイン済みはDiscord案内を省く7steps）。Welcome/Appearance/Background/Search/AI/Favorites・Shortcuts/Discord/Completeへ進み、各Skip、Back、Later、設定画面からの再実行に対応。次へ進む際に設定と進捗を同じIndexedDB transactionへ保存する。進捗は端末専用で同期しない。設定は既存の同期対象。背景ステップでは実際の単色を選択でき、画像/動画はPhase 7で追加する。

Phase 6の機能ゲートはdocs/phase6-gate.mdで確認済み。実Discord認証後の名前・Profile、実OS reduced motion切替は未確認を最終監査へ留保。Version 1.0全体は未完成。
